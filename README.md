# Holberton School — Higher Level Programming

Python and JavaScript modules covering ORM, serialization, server-side rendering, REST APIs, and DOM manipulation.

## Modules

| Module | Language | Topics |
|--------|----------|--------|
|  | Python | SQLAlchemy ORM, MySQL queries |
|  | Python | JSON, pickle, XML serialization formats |
|  | Python | Jinja2 templates, Flask SSR |
|  | Python | REST endpoints, HTTP methods, status codes |
|  | JavaScript | Variables, functions, closures, loops |
|  | JavaScript | DOM queries, events, dynamic content |

## Run

```bash
# Python modules
python3 <script>.py

# JavaScript modules
node <script>.js
```

## Requirements

- Python 3.x
- Node.js
